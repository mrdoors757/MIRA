# MIRA — Share your world

Адаптивная социальная сеть MIRA в тёплой светлой палитре. В проекте есть лента, профили, истории и фото-рилсы.

## Возможности
- Регистрация и вход по никнейму и паролю (пароли хешируются bcryptjs).
- Сессия пользователя.
- Публикации с текстом, фотографией и местом.
- Лайки и комментарии.
- Поиск пользователей, подписки, редактирование профиля и аватара.
- Сохранение публикаций в браузере.
- Истории с фотографией и подписью, доступные в течение 24 часов.
- Фото-рилсы с подписью и просмотром в отдельном окне.
- Сообщество из 12 демо-профилей с фотопортретами и дополнительными публикациями.
- Короткие чаты: по одному первому сообщению выбранному собеседнику.
- Демо-истории и фото-рилсы для знакомства с интерфейсом.
- Адаптивный интерфейс для мобильных устройств и компьютеров.
- Демо-лента с фотографиями, чтобы интерфейс не выглядел пустым при первом запуске.

## Запуск на Windows
1. Установи Node.js LTS с https://nodejs.org/.
2. Распакуй архив и открой папку `MIRA` в VS Code.
3. В терминале выполни:

```bash
npm install
npm start
```

4. Открой http://localhost:3000.

## Важно
Это полноценный локальный starter/MVP, но не готовая к публичному запуску крупная социальная сеть. Данные хранятся в `data/db.json`, изображения — в `uploads/`; для продакшена нужны база данных, облачное хранилище изображений, ограничение частоты запросов, защита от спама, проверка контента, HTTPS и постоянное хранилище сессий. Перед публикацией задай `SESSION_SECRET` через переменные окружения и не используй секрет по умолчанию.

Демо-публикации, истории, фото-рилсы и фотопортреты нужны для предварительного просмотра. Изображения загружаются с Unsplash и требуют подключения к интернету. Реальные публикации, истории и рилсы пользователей хранятся на сервере. Демо-чаты сохраняются локально в браузере и поддерживают одно первое сообщение на каждого собеседника; это пример интерфейса, а не сетевой обмен сообщениями между аккаунтами. Видео для рилсов пока не загружается: публикация работает как фото с короткой подписью.


## Что добавлено в v3
- **Видео (как YouTube):** загрузка MP4/WebM/MOV до 300 МБ с прогрессом, плеер с перемоткой, просмотры, лайки, комментарии, поиск, рекомендации, ссылка `/#video-<id>`.
- **Настоящие чаты (как Telegram):** личные сообщения между аккаунтами, фото, непрочитанные, галочки ✓/✓✓, обновление раз в 3 секунды, поиск людей. Данные: `db.videos`, `db.messages` в `data/db.json`. Новых зависимостей нет.

## v4: демо-контент
- 12 демо-людей — настоящие аккаунты: на них можно подписаться, написать (отвечают автоответом) и лайкнуть их видео.
- Демо-видео выходят по одному каждые 30 сек, без повторов (сначала 5, дальше по одному). Пул: `seed-videos.js` + любые .mp4/.webm/.mov, которые ты положишь в `demo-videos/`.
- Под видео и на карточках видны просмотры и лайки; у демо-видео просмотры растут.

## v5
- Видео больше не берутся с чужих серверов: 48 уникальных роликов (генеративная анимация) лежат в `demo-videos/` с превью-постерами, играют без интернета. Первые 12 появляются сразу, остальные — по одному каждые 30 сек, без повторов.
- Демо-посты, истории и рилсы получают уникальные фото (picsum.photos по seed), а не 3 повторяющиеся картинки.
- Хочешь ещё видео — просто положи .mp4/.webm/.mov в `demo-videos/`.
